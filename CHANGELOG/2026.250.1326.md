# 2026.250.1326 — ci: fix the install-test's mcp-serve assertion under set -e (B18)

## Summary

The merged install-test assertion (PR #1) captures the mcp-serve probe via `serve=$?` after a bare subshell — but the script body runs under `set -e`, so the probe's EXPECTED exit 124 (ran-until-timeout) aborts the subshell's parent before the capture, making the assertion unpassable in both the success and failure cases. `( ... ) || serve=$?` captures the status without tripping set -e (124 → pass; an early exit → the test fails loudly).

## How tested

The change is a one-line shell correction in the install-test workflow; the CI install-test job exercises the probe on every run (the container, no systemd — the foreground probe path). Validator re-judgment is the gate.
