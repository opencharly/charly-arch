# 2026.256.1304 — feat: package the charly-lib shared plugin host + symlinks

## Summary

Cut the `charly-arch` packaging over to the **shared plugin host**. Instead of downloading charly's
per-plugin binaries tarball, the workflow now:

1. downloads the **pinned** `charly-lib` release (host `charly-lib-linux-{amd64,arm64}` +
   `*.providers`) — new `charly_lib_version` input, default `v2026.256.1131`;
2. builds the packaging plugins dir as `charly-lib` (host) + `plugin-<word>` **symlinks** →
   `charly-lib` + their `.providers` manifests;
3. installs that same layout under `/usr/lib/charly/plugins` for the local `charly`.

`charly generate-packages` (packagekit hard cutover, opencharly/sdk#258) stages the host **once** +
symlinks, so the per-plugin re-linked SDK/spec closure leaves every package. The loader contract is
unchanged (`.providers` beside an executable named `plugin-<word>`).
