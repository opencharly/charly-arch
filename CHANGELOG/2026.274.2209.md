# 2026.274.2209 — docs(readme): runnable pacman-key steps — add a key file, lsign the real fingerprint

## Summary

The README's "Add the repository" block could not be run as written:

```sh
pacman-key --add https://opencharly.github.io/charly-arch/charly.gpg   # --add takes key FILES, not a URL
pacman-key --lsign-key <KEYID>                                       # a placeholder the reader cannot fill in
```

It now mirrors what this repo's own `check-arch-repo` bed does (`charly.yml:64-70`): download `charly.gpg` to a file, `pacman-key --add` the file, and locally sign the key. The real fingerprint is now written out.

Part of opencharly/charly#747 (README and docs truth audit). The same corrected steps go into the charly README's install section.
