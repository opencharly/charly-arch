charly-arch

The Arch Linux package repository for charly — the OpenCharly CLI and its composed toolchain, packaged as .pkg.tar.zst for amd64 and arm64.

Add the repository

pacman-key --add https://opencharly.github.io/charly-arch/charly.gpg
pacman-key --lsign-key <KEYID>

Append to /etc/pacman.conf:

[charly]
Server = https://opencharly.github.io/charly-arch/amd64
SigLevel = Required
pacman -Sy
pacman -S charly

For arm64 hosts, use Server = https://opencharly.github.io/charly-arch/arm64.
